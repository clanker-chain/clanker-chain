# clanker-chain website

Local Astro + Starlight site: landing at `/`, docs under `/docs`.

```bash
cd website
npm install
npm run dev
```

- Landing: http://localhost:4321/
- Docs: http://localhost:4321/docs/get-started/

```bash
npm run build
npm run preview
```

Content is seeded for closed-beta onboarding. Not deployed in this package yet.
